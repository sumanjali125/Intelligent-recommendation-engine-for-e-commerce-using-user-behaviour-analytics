## 🚀 Quick Start (Choose One)

### Option A: Run Locally (2 minutes)
```bash
cd ecommerce-recommender/frontend
npm install
npm run dev
```
Opens at http://localhost:3000

### Option B: Deploy to GitHub Pages (5 minutes)
```bash
# Create repo on GitHub named 'ecommerce-recommender'
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/ecommerce-recommender.git
git push -u origin main

cd frontend
npm install
npm run deploy

# Enable Pages: Settings → Pages → gh-pages → Save
```
Live at https://YOUR_USERNAME.github.io/ecommerce-recommender/
